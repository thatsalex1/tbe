DATABASE SETUP
═══════════════════════════════════════════════════════════════════════════════

If database table doesn't exist:
  1. Copy SQL from setup.html page
  2. Go to https://supabase.com
  3. Click your project
  4. Click "SQL Editor" → "New Query"
  5. Paste SQL code
  6. Click "Run" button
  7. Return to setup.html, refresh
  8. Should show "✓ Database setup complete!"

═══════════════════════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Open Console: F12 (press Ctrl+Shift+I)
  ✓ Look for red errors
  ✓ Check blue/green info logs
  ✓ "User created" indicates success
  ✓ "✓" = good, "✗" = error

Error: "Database connection failed"
  → Check if Supabase is accessible (supabase.com)
  → Check internet connection
  → Check console for details

Error: "Email already registered"
  → Use different email
  → Or delete user from Supabase

Page won't load:
  → Check URL starts with http://127.0.0.1:5500
  → Check Live Server is running
  → Refresh browser (Ctrl+R)

Can't select role:
  → Open console (F12)
  → Look for JavaScript errors
  → Try refreshing page
